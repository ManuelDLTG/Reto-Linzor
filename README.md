# Reto Linzor — Manuel De la Tejera González

Proceso de investigación y análisis para el "Reto Linzor" de Linzor Capital Partners:
identificar una empresa objetivo en México o Colombia (ventas anuales sobre ~US$10M),
evaluarla como potencial inversión de Linzor, y construir el caso de inversión en 3 slides.
Deadline: 30 de septiembre de 2026.

Documentado como lo trabajaría un analista de PE: mandato del fondo → sourcing top-down →
screening cuantitativo → deep dive del target → memo de decisión → modelo → pitch.

## Estructura

```
01-research-linzor/         Quiénes son, qué buscan, patrones de inversión, portafolio
02-screening/               Long list de 33 empresas colombianas + matriz de scoring (Excel)
03-target-satrack/          Deep dive del target elegido: financieros, propiedad, mercado
03-target-satrack-backup-sincosoft/   Deep dive del respaldo (Sincosoft / Sinco ERP)
04-memo/                    Memo de decisión Fase 3 (comparación y recomendación)
05-pitch/                   Notas para las 3 slides finales
06-modelo/                  Modelo financiero y valuación (Fase 4, pendiente)
```

## Estado actual

- **Target principal:** Satrack S.A.S. (Medellín) — telemática y gestión de flotas,
  réplica directa de la tesis de Numaris (México) en un mercado fragmentado colombiano.
- **Respaldo:** Sincosoft S.A.S. / Sinco ERP (Bogotá) — ERP vertical para construcción
  e infraestructura, mejor margen pero narrativa menos directa con el portafolio de Linzor.
- **Pendiente:** confirmar representante legal / propiedad formal de Satrack vía Cámara
  de Comercio de Medellín (RUES presentó fallas de acceso durante la investigación);
  modelo financiero completo (Fase 4); redacción final de las 3 slides.
